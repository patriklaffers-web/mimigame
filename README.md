# Bone Blaster

A simple 2D top-down shooter: blast waves of skeletons with your pistol. If they kill you, you respawn after 2 seconds (with brief invulnerability) and the fight continues.

## Play

Open `index.html` in a browser — no build step or dependencies.

## Controls

- **WASD / arrow keys** — move
- **Mouse** — aim
- **Click / hold** — shoot
- **R** — reload (12-round magazine, auto-reloads when empty)

Tougher, tan skeletons with red eyes take more hits. Each cleared wave brings a bigger, faster one.
