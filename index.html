How this works

The hub runs the official SPIKE 3 firmware. This page uploads a small Python program for each direction into the program slots above (overwriting whatever was there), then starts and stops those programs as you press and release the buttons. If the car drives backwards, toggle both reverse boxes; if it turns the wrong way, swap the ports.
